# opticsuab.github.io

Sitio web del Grupo de Óptica de la Universitat Autònoma de Barcelona: **https://opticsuab.eu**

La web está disponible en inglés, castellano y catalán mediante el selector del encabezado. El inglés es el contenido de origen; las traducciones se guardan en `data/i18n/es/` y `data/i18n/ca/`. Al actualizar contenido en el panel Pages CMS, revisa también las traducciones correspondientes. Los títulos y las citas bibliográficas se mantienen en el idioma de publicación.
